# SOLE CULT

Premium immersive sneaker storefront. Final approved visual: light warm-cream architectural showroom, floating sneaker, Shop and About tabs, top-right search/profile/cart, bottom sneaker thumbnails without prices or pagination pills, product information and size selection on the right. Selecting a sneaker triggers a 360° flying transition. Shopify and WhatsApp commerce integrations follow in later phases.

## Development

```bash
npm install
npm run dev
```

This repository is public. Never commit Shopify private credentials or environment secrets.
